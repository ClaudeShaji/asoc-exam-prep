# Install the app

ASOC Exam Prep is distributed as an APK file on GitHub. It isn't on the Play Store.

## Requirements

- An Android phone or tablet running **Android 8.0 or newer**.
- About 15 MB of free space.
- No account and no internet connection are needed once it's installed. Everything,
  including the notes, questions and audio, is inside the app.

## Download and install

1. On your phone, open the
   [latest release](https://github.com/ClaudeShaji/asoc-exam-prep/releases/latest).
2. Under **Assets**, tap `ASOC-Exam-Prep-<version>.apk` to download it.
3. Open the downloaded file, from the browser's download notification or your Files app.
4. If Android asks, allow your browser or Files app to **install unknown apps**, then go back
   and tap **Install**.
5. Open **ASOC Exam Prep** from your app drawer.

!!! tip "Checking the download"
    Each release also has an `.apk.sha256` file. To check the APK wasn't damaged or changed,
    compare its SHA-256 checksum with the one in that file. Many file managers can show a
    file's SHA-256, and on a computer you can run `sha256sum ASOC-Exam-Prep-<version>.apk`.

## Updating

Download the newer APK from Releases and install it over the old one. Your progress is kept.

!!! warning "Coming from a build older than 0.8.0 on GitHub"
    Test builds shared before the first GitHub release were signed with a different key.
    Android won't install the GitHub release over one of those. Uninstall the old app first,
    then install the new one. Uninstalling erases the old app's progress.

## Uninstalling

Long-press the app icon and choose **Uninstall**, or use **Settings → Apps** on your phone.
This removes all your progress, which is stored only on your phone.
